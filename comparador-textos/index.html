Cómo funciona

  • Todo pasa en tu navegador. Los textos no se envían a ningún servidor: puedes usarlo sin internet y con documentos privados.
  • Compara de verdad, no línea contra línea. Usa el algoritmo de Myers (el mismo tipo de cálculo que usa git diff) para encontrar el conjunto mínimo de cambios.
  • Resalta la palabra exacta. Cuando una línea fue editada, marca solo el trozo que cambió.
  • El parche que descargas está en formato unificado estándar, el que entienden git apply y patch.

Comparador de Textos — funciona sin conexión, sin cuentas y sin enviar nada a internet.
