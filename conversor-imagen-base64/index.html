¿Para qué sirve?

Incrustar un logo o un icono dentro del propio HTML o CSS evita una petición extra al servidor y hace que la página cargue más rápido.

Correos y APIs

Muchas plantillas de correo y APIs (JSON) sólo aceptan imágenes como texto: Base64 es justo ese formato.

Ojo con el tamaño

Base64 ocupa un 33 % más que el archivo original. Ideal para imágenes pequeñas (menos de 100 KB), no para fotos grandes.
